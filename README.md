# Branch Context

Branch Context is optional, branch-scoped working context for coding-agent
workflows. It supports resumability, decision traceability, handoffs, and
reproducible investigations without requiring every repository to adopt it.

This branch contains the Branch Context for the Python scripts repository.

- [Branch Context guidance](https://github.com/mikebd/ai-agent-skills/tree/main/shared/references/branch-context)
- [Python scripts repository](https://github.com/mikebd/py-scripts)

This branch is part of the [public Branch Context catalog](https://github.com/mikebd/public-branch-context/blob/main/README.md).
